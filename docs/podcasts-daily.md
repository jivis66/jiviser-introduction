# 播客Daily 收集指南

> **用途**: 本文件用于配置AI助手收集和推荐优质播客节目，涵盖科技、商业、设计、人文等领域
> **推送时间**: 每日 07:30 (晨间通勤) 或 21:30 (晚间放松)
> **推送渠道**: Telegram
> **输出语言**: 中文（外文节目提供摘要翻译）
> **内容形式**: 每日1-2个精选单集 + 节目亮点摘录 + 适合场景推荐

---

## 元数据配置

```yaml
schedule:
  - "07:30"  # 晨间通勤：轻松资讯、行业动态
  - "21:30"  # 晚间放松：深度对话、人文思考
timezone: "local"
output_format: "podcast-curation"
content_mix:
  morning:
    - 科技资讯类（20-40分钟）
    - 商业快讯类（15-30分钟）
  evening:
    - 深度对话类（60-120分钟）
    - 人文故事类（30-60分钟）
    - 单集亮点摘录（3-5条）
rotation:
  monday: "科技与开发者"
  tuesday: "产品与创业"
  wednesday: "商业与投资"
  thursday: "设计与创意"
  friday: "人文与生活方式"
  saturday: "本周播客精华"
  sunday: "下周节目预告"
preferences:
  exclude: ["低质量录音", "过度广告", "无实质内容闲聊"]
  prioritize: ["信息密度高", "嘉宾优质", "制作精良", "观点独特"]
focus_areas:
  - tech_development    # 技术开发者
  - product_startup     # 产品创业
  - business_investment # 商业投资
  - design_creative     # 设计创意
  - humanities_life     # 人文生活
delivery:
  channel: "telegram"
  format: "markdown"
  include_timestamps: true  # 重要时间节点
```

## 播客质量评估标准

### ✅ 优先收录

| 类型 | 标准 | 示例 |
|-----|------|------|
| 嘉宾质量 | 行业专家、一线实践者 | 创始人、技术负责人 |
| 信息密度 | 干货多、闲聊少 | 有准备的问题清单 |
| 制作水准 | 音质清晰、剪辑得当 | 专业录音设备 |
| 观点独特 | 提供独家视角或内幕 | 第一手经验分享 |
| 更新稳定 | 有规律的更新频率 | 周更或双周更 |
| shownotes | 提供详细时间戳和链接 | 方便回溯 |

### ❌ 排除内容

- 音质太差影响收听体验
- 过度商业广告植入
- 内容空洞、纯闲聊
- 长时间断更（超过3个月）
- 抄袭或无授权转载
